
# MP2a & MP2b — Mining Tower Upgrading System

## Overview

A Unity-based sci-fi space simulation featuring interconnected towers, resource systems, enemies, and progression mechanics. MP2b extends the project with a structured Mining Tower upgrading system.

## MP2a — Interconnected Space Simulation

- **Towers:** Includes combat, support, and resource-focused towers such as Bioship, Leviathan, Ophanim, ISS, Blocky Alien Station, Laser Tower, and resource facilities.
- **Resources:** Asteroids and other resource sources support extraction and resource conversion mechanics.
- **Enemies:** Features enemy types such as Sun, Blackhole, and Crystal Enemy.
- **Interconnected Gameplay:** Combines tower interactions, resource management, and combat-oriented systems.

## MP2b — Mining Tower Upgrading System

The Mining Tower provides a resource progression loop:

1. **Mine** asteroids to collect resources.
2. **Process** unloaded cargo into resource barrels.
3. **Sell** barrels to earn Credits.
4. **Upgrade** the tower to unlock new capabilities.

Six upgrade paths are available:

- **Mining Head** — Unlock higher-tier asteroid families.
- **Storage** — Increase resource capacity.
- **Engineer** — Upgrade engineering capabilities.
- **Power** — Upgrade power systems.
- **Walls** — Improve defenses.
- **Weapons** — Upgrade offensive capabilities.

The progression system features **21 mastery thresholds**, stage-gated upgrades, and contextual feedback for invalid interactions.
